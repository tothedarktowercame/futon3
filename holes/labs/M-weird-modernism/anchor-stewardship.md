## 2. Succession plan

**Trigger for review:** Each projection-surface increment (foreword draft revision, HEAD reading update, candidate-upgrade promotion). The mission operates in perpetual-projection mode (M-weird-modernism.md line 3: "no closure phase scheduled"), so the review cadence is per-increment, not per-terminal-phase.

**Trigger for anchor rotation:** An anchor is candidate for rotation when:
1. A candidate upgrade (projection surface 3) lands and shifts a discriminative dimension such that the current anchor no longer spans it. Example: if Candidate 3 (brand-naming-the-Logos as named flexiarg, §lines 426-428) is promoted, the brand-name passage may graduate from anchor to pattern-file, and a new anti-pattern instance is needed as anchor.
2. A new triangulation domain (the current five: PKD, Heraclitus, Norns, Parr-Friston, Buddhist Magga) surfaces a contrast that represents the model's extremes better than the original PKD-essay anchors.
3. The theoretical base evolves (e.g., Hamilton's Principle grounding, §lines 669+) such that the anchors' connection to the formal apparatus weakens.

**Rotation procedure:**
1. The outgoing anchor is archived with its cycle identifier (see §4 below) in this document's archive section.
2. The incoming anchor is named with date and selection rationale (same format as §1).
3. The review event is recorded in `anchor-review-log.edn`.
4. Claims made with the outgoing anchor remain comparable via the archive's cycle identifier (see §5).

**No rotation is currently indicated.** The first formal review (2026-07-11) confirms both anchors still span their discriminative dimensions after the Parr-Friston MAP-phase grounding and the Eightfold Path correspondence. See `anchor-review-log.edn`.
